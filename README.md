# JungleMind

Downloadseite für JungleMind, eine Windows-App mit Pick- und Ban-Empfehlungen aus dem eigenen Champpool für die Champion-Auswahl in League of Legends.

Seite: https://karlson79.github.io/draft-coach/

JungleMind wird nicht von Riot Games unterstützt und spiegelt nicht die Ansichten oder Meinungen von Riot Games oder anderen Personen wider, die offiziell an der Produktion oder Verwaltung von Riot-Games-Eigentum beteiligt sind.
